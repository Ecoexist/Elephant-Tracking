Scratch Map

An interactive map showing my running and cycling routes. Built with Leaflet and powered by Strava data, this visualization displays GPS tracks from various outdoor activities across different locations.

Strava Heatmap

A comprehensive heatmap visualization of all my Strava activities. This interactive map uses heat mapping techniques to show activity density and patterns across different regions and time periods.

Travel Map

An all-encompassing travel map combining GPS data from multiple sources including Strava activities and general travel logs. This visualization provides a complete overview of my geographic footprint.

Elephant Tracking Dashboard

A real-time elephant tracking dashboard for conservation monitoring. This interactive platform displays GPS collar data from elephants in protected areas, helping researchers track movement patterns and behavior.
