Light map (100 m)

White cells must lie in the top 50% by intersection count, top 10% by mean segment speed, and top 10% by directional coherence (aligned movement through the cell; see below). Solid white on a ~30% transparent dark veil.

Cell identification (100 m Web Mercator grid)

Each point is projected from WGS84 (φ, λ) in degrees to Web Mercator metres (x, y) using x = R·λrad, y = R·ln(tan(π/4 + φrad/2)) with R = 6 378 137 m (same as EPSG:3857). Cell indices are ix = ⌊x / 100⌋, iy = ⌊y / 100⌋; the cell id is ix,iy (one square = 100 m × 100 m in projected metres). Map rectangles use the geographic bounds of that square’s four corners.

Distance (Haversine, km)

a = sin²(Δφ/2) + cos φ₁ · cos φ₂ · sin²(Δλ/2)
d = 2 · Rearth · atan2(√a, √(1−a)),   Rearth = 6371 km

where Δφ, Δλ are latitude and longitude differences in radians on a sphere.

Speed per segment (km/h)

v = (dkm / Δts) × 3600

with Δt the time in seconds between consecutive GPS fixes A and B on the same animal tag (after sorting by time). Segment speed is accumulated into every grid cell the straight line A→B crosses in (x, y) space (sampled along the chord).

Direction (unit vector & “directional dot” / coherence)

In Mercator metres, segment A→B has Δx = xB − xA, Δy = yB − yA. The unit direction is û = (Δx, Δy) / √((Δx)² + (Δy)²). For each cell the segment crosses, we add this same û to a running vector sum R = Σ û over N segment crossings.

c = |R| / N   ∈ [0, 1]

c is the mean resultant length: if all û agree, c → 1; if they cancel, c → 0. Equivalently, with mean direction r̂ = R/|R|, each term contributes û · r̂ and c is their average—so high c means movement through the cell is directionally consistent. Highlighted cells are also in the top tier of c among cells that have segment data.
