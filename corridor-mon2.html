Corridor monitoring (GCS + AGOL) — how it works

Data sources

Road crossings load the same way as the main corridor page: Google Cloud Storage (road_crossings.json) via public URL and/or the road-crossings-process API with your admin sign-in. ArcGIS Online points load from the configured FeatureServer layer (query f=json, paginated).

Corridor polygons and NG_Roads are local GeoJSON. AGOL uses the public Elephant_Corridors_Monitoring_Form_view service (layer 0). If you switch to a private layer and see Token Required, set AGOL_PORTAL_TOKEN in the script.

Filters and elephant list

Year / Month apply to both GCS crossings and AGOL features (when a parseable date exists on each record). The Crossings per elephant table lists GCS-only counts and only filters GCS points on the map; AGOL points always match the date filter and are always shown.

Map and corridor usage

GCS crossings are drawn in purple; AGOL points in orange. Corridor usage counts all filtered points (GCS + AGOL) inside each corridor and builds outside-corridor bands from the combined set (same rules as the main corridor page).

Stats

Road crossings / inside / outside / last crossing refer to the GCS subset (with elephant filter). AGOL points is the date-filtered AGOL count. The footer under “Last GCS crossing” can show the latest AGOL time when available.
